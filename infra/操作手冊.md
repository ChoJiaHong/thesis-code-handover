# 基礎設施建置操作手冊

本目錄為建置Kubernetes叢集本身與其GPU共享機制、監控系統所需的腳本，與`controller/`、
`agentmanager/`等「應用程式層」部署不同，屬於「叢集建置」層級，須在應用程式部署**之前**
完成。對應論文2-3節GPU Time-Slicing機制與5-1-1節硬體配置之實際建置方式。

## 建置順序

### 1. Kubernetes 叢集建立

```bash
# 於 Master 節點執行
bash k8s_master_install.sh          # 安裝kubeadm/kubelet/kubectl、初始化叢集、部署Flannel CNI

# 於各 Computing/Worker 節點執行
bash k8s_computing_install.sh       # 安裝相同套件，並加入叢集（join token需從master節點
                                     # 執行k8s_master_install.sh後的輸出取得，已用佔位符替代）

# 如需更新containerd設定（例如cgroup driver問題排解）
bash update_containerd_config_master.sh
```

### 2. NVIDIA GPU 支援

```bash
bash NVIDIA_container_rumtime_install.sh   # 安裝nvidia-container-toolkit，設定containerd runtime
```

### 3. GPU Time-Slicing（對應論文2-3節核心機制）

```bash
bash helminstallgpuoperator.sh
```

此腳本安裝NVIDIA GPU Operator（v24.3.0），套用`time-slicing-config-all.yaml`
（設定 `replicas: 20`，即每張GPU切分20個時間片），並patch ClusterPolicy套用此設定。
**這是論文2-3節「GPU Time-Slicing機制」與4-1-10節容量量測方法的實際基礎設施依據**。

### 4. Ingress（可選，供外部存取Grafana/Prometheus用）

```bash
bash "helm_nginx ingress controller.sh"
```

### 5. 監控系統（Monitor元件的Prometheus依賴，見`monitor/操作手冊.md`）

```bash
bash helminstallprometheus.sh   # 安裝kube-prometheus-stack v60.3.0，套用values.yaml
```

`values.yaml`含自訂設定，包括：
- `nodeSelector`／`affinity`以`arha-node-type`標籤指定運行節點（對應
  `docs/aws_deploy_commands.md`中`kubectl label nodes ... arha-node-type=...`步驟）
- Alertmanager設定中有一條webhook指向
  `http://monitor-service.arha-system.svc.cluster.local:80/alert`——**已確認為未使用之
  殘留設定**（2026-09-03）：Monitor實際上未對外開放`/alert`端點接收請求（`monitor.py`
  內未見任何HTTP server/route定義），節點故障偵測機制實際上是Monitor主動輪詢
  Prometheus之`kube_node_status_condition`（見`monitor/操作手冊.md`），並非被動接收
  Alertmanager告警。此條webhook設定部署時可忽略／移除，不影響系統運作。

部署`PodMonitor.yaml`使Prometheus能抓取推論服務Pod（label `app: infer`）之`/metrics`端點
（1秒間隔）。`grafana-prom-ingress.yaml`為Grafana／Prometheus之對外存取路徑設定（可選）。

## 應用程式層Persistent Volume（供Controller等元件掛載log/資料）

```bash
kubectl apply -f arha-logs-pv.yaml
kubectl apply -f arha-logs-pvc.yaml
kubectl apply -f arha-pv.yaml
kubectl apply -f arha-pvc.yaml
```

對應`controller-deployment.yaml`中掛載的`logs-volume`、`information`兩個volume。
`controller_install.sh`彙整了建立命名空間、套用PV/PVC、部署Controller的完整順序，
可作為Controller首次部署的參考腳本。
