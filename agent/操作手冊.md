# Agent 操作手冊

## 用途

使用者端代理，對應論文4-3-1節。負責：
- 將AR終端（或模擬器）擷取之影像轉送至Controller指派之推論服務實例
- 依Controller下發之路由與速率指令，以leaky-bucket rate limiter控制實際請求發送頻率
- 每位使用者對應一個Agent，可同時處理多項訂閱服務（gesture/pose/object）

## 啟動方式

```bash
python3 agent_refactored.py \
  --ip <對外IP，預設10.52.52.50> \
  --port <HTTP埠，預設8888> \
  --ws-port <WebSocket埠，預設8889> \
  --controller-ip <Controller IP，預設10.52.52.126> \
  --controller-port <Controller埠，預設30004> \
  --service <服務名> <服務IP> <服務埠> <初始頻率>   # 可重複多次，對應多項訂閱服務
```

範例（訂閱gesture與pose兩項服務）：

```bash
python3 agent_refactored.py \
  --service gesture 172.31.32.40 50051 10 \
  --service pose 172.31.32.40 50052 10
```

## 依賴

- `gesture_pb2.py`／`pose_pb2.py`／`inference_pb2.py`（及對應`_grpc.py`）：gRPC訊息與服務定義
- `status_pb2.py`：非直接使用，但`inference_pb2.py`內部依賴此模組，缺少會import失敗

## 部署方式

由AgentManager透過SSH在Agent Node上建立容器並啟動，非獨立部署；正式環境中的image
版本可由AgentManager之`config.json`的`agent_image`欄位查得。
