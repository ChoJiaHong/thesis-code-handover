# 繪圖程式操作手冊

## `plot_compare.py`：多方法比較折線圖（對應論文fig5/6/7、fig_ablation1/2）

```bash
python3 plot_compare.py \
  <標籤1>:<CSV路徑1> <標籤2>:<CSV路徑2> [<標籤3>:<CSV路徑3> ...] \
  [--align=<標籤>] [--warmup=<秒數，預設20>] \
  [--until=<秒數>] [--from=<秒數，預設0>] \
  <輸出檔.png或.pdf>
```

- 每個位置參數為`標籤:CSV路徑`（冒號分隔），標籤可自訂（如`ga_bf`／`ems`／`lsr`）
- `--until`：統計時間窗口右界，各情境對應值見`docs/data_provenance.md`
  （實驗一450秒、實驗二390秒、實驗三230秒）
- `--warmup`：排除開頭暖機時間之秒數，預設20秒
- 消融實驗（有／無過渡期SLA維持機制比較）用法相同，將兩份CSV分別標記為
  `ga_bf`（有機制）／`ga_bf_no`（無機制）即可

具體使用範例已附在`docs/data_provenance.md`，直接對應`data/`目錄下各實驗資料夾。

## `plot_trace.py`：單次實驗逐服務詳細圖（對應論文fig5b/c/d、fig6b/c/d、fig7b/c/d）

```bash
python3 plot_trace.py <CSV路徑> [<輸出檔.png或.pdf>] [--panels=<子面板代號組合>]
```

7個子面板（代號a-g）：使用者數/達標率、各服務Effective FPS、各服務平均延遲、
各服務Invalid FPS、節點部署Gantt圖等，`--panels=bcd`可只保留指定子面板組合
（用於「以服務區分、每個方法一張圖」時省去重複面板）。

**Panel (e)（節點部署Gantt圖）注意**：若CSV之`node_topology`欄位全為`{}`，該面板會
顯示「data not available」，這是`service.json`更新時間差造成的正常現象，不代表
服務未運行。
