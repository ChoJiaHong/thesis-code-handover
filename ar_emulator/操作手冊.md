# AR Emulator 操作手冊

## 用途

實驗用之使用者流量模擬器，模擬AR終端擷取影像並透過WebSocket傳送資料流，取代真實AR
眼鏡硬體以利大規模自動化實驗。由`experiments/experiment_ctrl.py`／
`experiments/experiment_ctrl_v2.py`以子進程方式呼叫（見`experiments/操作手冊.md`）。

## 啟動方式（通常由experiment_ctrl系列腳本自動呼叫，一般不需手動執行）

```bash
python3 AR_emulator_nosub.py <emulator實例ID> \
  [<服務清單，逗號分隔，預設 "pose,gesture,object">] \
  --metrics-file <輸出metrics json路徑> \
  --agent-manager-ip <AgentManager IP，預設10.52.52.111> \
  --agent-manager-ws-port <AgentManager WebSocket埠，預設30008>
```

範例：

```bash
python3 AR_emulator_nosub.py 1 pose,gesture --metrics-file ./metrics/agent_1.json \
  --agent-manager-ip 172.31.22.137 --agent-manager-ws-port 30008
```

## 必要檔案

`1280hand.jpg`：**必須與`AR_emulator_nosub.py`放在同一目錄**，作為模擬傳送之測試影像，
缺少此檔案會導致呼叫端（`experiment_ctrl.py`）直接檢查失敗、拒絕啟動。

## 依賴

僅使用標準庫、`requests`、`websockets`，不依賴任何gRPC/proto檔案（走WebSocket通訊，
非gRPC），依賴關係單純。
