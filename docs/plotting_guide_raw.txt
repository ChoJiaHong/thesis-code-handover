## 1. `plot_trace.py`：單次實驗 Trace 圖

**最常用**，論文用圖。5 個面板：

| Panel | 內容 |
|-------|------|
| (a) | Users、N_sat、滿足率 |
| (b) | 各服務 Effective FPS（含 f_l 參考線） |
| (c) | 各服務平均延遲（超 2000ms 截斷） |
| (d) | 各服務 Invalid FPS（real − effective） |
| (e) | 各節點服務部署 Gantt 圖 |

## 2. `plot_experiment.py`：8-panel 詳細指標圖

除 Trace 圖外的補充視圖，包含 Pod 數量、容量使用率等系統指標。

**8 個面板：**

| Panel | 內容 |
|-------|------|
| 1 | Users vs N_sat |
| 2 | Satisfaction Rate |
| 3 | Real FPS（各服務） |
| 4 | Effective FPS（各服務） |
| 5 | 平均延遲（各服務） |
| 6 | 整體平均回應時間 |
| 7 | Pod 數量變化 |
| 8 | 累計 Pod 變更次數 + 容量使用率 |

**使用方式：**

```bash
# 預設輸出 PNG
python3 plot_experiment.py results/ga_bf/s1_20260527_230620.csv
```

**輸出：** `{CSV 檔名去副檔名}_plot.png`（固定 PNG，無法透過參數更改）

## 3. `plot_compare.py`：多 Solver 比較圖

用於論文中比較不同演算法。3 個面板：

| Panel | 內容 |
|-------|------|
| (a) | sat_rate vs n_users（散點，各 solver 一條線） |
| (b) | N_sat 時序（smoothed） |
| (c) | Pose 延遲時序（smoothed，截斷 2000ms） |

**使用方式：**

```bash
# 輸出 PDF
python3 plot_compare.py \
    ga:results/ga/s1_20260527_213320.csv \
    ems:results/ems/s1_xxx.csv \
    lsr:results/lsr/s1_xxx.csv \
    comparison_s1.pdf

# 輸出 PNG（改副檔名即可）
python3 plot_compare.py \
    ga:results/ga/s1_20260527_213320.csv \
    ems:results/ems/s1_xxx.csv \
    lsr:results/lsr/s1_xxx.csv \
    comparison_s1.png

# 兩個 solver 比較（不指定輸出，自動命名）
python3 plot_compare.py \
    ga:results/ga/s1_20260527_213320.csv \
    ems:results/ems/s1_xxx.csv
```

**輸出：** 指定的檔名（副檔名決定格式），或自動命名為 `comparison.pdf`

## 常見問題

| 問題 | 原因 | 解法 |
|------|------|------|
| `KeyError: 'node_topology'` | 舊版 CSV 沒有此欄位 | Panel (e) 會自動顯示提示訊息，不影響其他 panel |
| Panel (e) 全為空白 | `node_topology={}` 在所有時間點 | 正常現象，service.json 與 pod 實際狀態有時間差 |
| 圖片無法開啟 | 在無 GUI 的伺服器上執行 | 用 `scp` 把 PDF/PNG 下載到本機查看 |
| 延遲圖線條被截斷 | 超過 2000ms 閾值（`LAT_CAP=2000`） | 修改 `plot_trace.py` 第 111 行的 `LAT_CAP` 值 |
