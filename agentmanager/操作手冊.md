# AgentManager 操作手冊

## 用途

接收新使用者（AR終端）的訂閱請求，於指定的Agent Node上以SSH建立對應的Agent容器，
並將訂閱需求轉發給Controller。對應論文4-3-1節「系統元件與職責」中AgentManager之角色。

## 啟動方式

```bash
python3 AgentManager_websocket_refact.py <Agent_Host數量> \
  <Agent_Host_IP_1> <帳號_1> <密碼_1> \
  [<Agent_Host_IP_2> <帳號_2> <密碼_2> ...]
```

`Agent_Host` 即實際建立Agent容器之目標主機（透過`paramiko`以SSH連線建立），數量可為1
或多台。實際帳密請勿寫在部署yaml明碼中（見下方安全性提醒）。

服務埠：HTTP 8888、WebSocket 50051。

## 主要設定檔

`config.json`：

```json
{
    "agent_controller_ip": "...",
    "agent_controller_port": 30004,
    "agent_ready_timeout": 45,
    "agent_image": "hiro08081/agent_refactored:..."
}
```
`agent_controller_ip`欄位要寫入controller的ip位址
`agent_image`欄位標明實際部署時使用的Agent image tag，**請對照當下實際運行的
`agent_refactored`版本更新此欄位**，避免建立出舊版Agent容器。

## 部署方式

`agentmanager-deployment.yaml`已將帳密欄位替換為佔位符
（`<AGENT_HOST_IP>`／`<AGENT_HOST_ACCOUNT>`／`<AGENT_HOST_PASSWORD>`），實際部署時
需自行填入正確值，**不建議明碼寫入yaml提交至版控**，建議改用Kubernetes Secret。
